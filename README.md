   - Deep temple maroon (`#3d050d`), radiant turmeric & gold gradients (`#f59e0b` / `#fde047`), and festive emerald leaf accents.

## 🚀 How to Run & View Locally

You can open the website directly in any web browser:
- Simply double-click `index.html`, or
- Right click `index.html` -> **Open with Google Chrome / Microsoft Edge / Firefox**.

Or serve with any static web server (e.g. VS Code Live Server, Python, or Node):
```bash
# Using Python
python -m http.server 8080

# Or with npx serve
npx serve .
```

## 🌐 Free One-Click Deployment Options

### Option 1: GitHub Pages
1. Push this folder to a GitHub repository (e.g., `pongal-karlsruhe-2027`).
2. Go to **Settings > Pages**.
3. Select `Branch: main`, `Folder: / (root)`, and click **Save**.
4. Your site will be live instantly with a free HTTPS URL!

### Option 2: Netlify / Vercel
1. Drag and drop the `pongal-karlsruhe-2027` folder into [Netlify Drop](https://app.netlify.com/drop).
2. It goes live in 5 seconds with a custom link you can share with the community!
