# 🌾 PONGAL 2027 • Karlsruhe Tamil Sangam Website

A festive, traditional, and modern responsive website crafted for the **Tamil Pongal 2027** celebration in the Karlsruhe / Durmersheim region.

- **Venue:** Beethovenstraße 4, 76448 Durmersheim-Würmersheim (Karlsruhe Region)

## 🎨 Design & Cultural Highlights

1. **Authentic Festive Aesthetics:**
   - Deep temple maroon (`#3d050d` / `#5c0b16`), radiant turmeric & gold gradients (`#f59e0b` / `#fde047`), and festive banana leaf green (`#14532d`).
   - Hanging Mango Leaf Toran (மா இலை தோரணம் / Mavilai Thoranam) across the top.
   - Traditional Kolam (புள்ளி கோலம்) geometric vector background and dividers.
   - Hand-crafted scalable vector illustration of the **Earthen Pongal Pot (மண் பானை)** with decorative yellow turmeric root garland (மஞ்சள் கொத்து), boiling sweet rice with rising steam particles, wood hearth flame, and tall purple sugarcane stalks (கரும்பு).
   - Sun God (Surya Bhagavan) radiant ray aura.

2. **Interactive Features:**
   - **Live Countdown Timer:** Counting down to Saturday, February 6, 2027 at 10:00 AM CET.
   - **Floating Marigold & Jasmine Flower Shower:** Interactive canvas animation with an on/off toggle button.
   - **Traditional Festive Chime:** Built-in Web Audio API synthesizer that plays an auspicious Carnatic pentatonic (Raga Mohanam) chime without requiring external audio downloads or network requests.
   - **1-Click Add to Calendar:** Generates standard `.ics` file for Apple/Outlook/Thunderbird, plus direct link to Google Calendar with prefilled venue, timings, and sheet link.
   - **Google Maps & Transit Directions:** Embedded responsive map for `Beethovenstraße 4, 76448 Durmersheim-Würmersheim`, with directions via S-Bahn S7/S8 from Karlsruhe Hbf and highway B36.
   - **WhatsApp & Social Share:** One-click WhatsApp sharing with pre-formatted invitation text.
   - **Interactive FAQ Accordion:** Providing answers about dress code, attendee count, family participation, and volunteering.

## 🚀 How to Run & View Locally

You can open the website directly in any web browser:
- Simply double-click `index.html`, or
- Right click `index.html` -> **Open with Google Chrome / Microsoft Edge / Firefox**.

Or serve with any static web server (e.g. VS Code Live Server, Python, or Node):
```bash
# Using Python
python -m http.server 8080

# Or with npx serve
npx serve .
```

## 🌐 Free One-Click Deployment Options

### Option 1: GitHub Pages
1. Push this folder to a GitHub repository (e.g., `pongal-karlsruhe-2027`).
2. Go to **Settings > Pages**.
3. Select `Branch: main`, `Folder: / (root)`, and click **Save**.
4. Your site will be live instantly with a free HTTPS URL!

### Option 2: Netlify / Vercel
1. Drag and drop the `pongal-karlsruhe-2027` folder into [Netlify Drop](https://app.netlify.com/drop).
2. It goes live in 5 seconds with a custom link you can share with the community!
